# 📌 About The Project

This project is a URL-shortening service designed to transform long URLs into short, easy-to-share links.

For example:

```text
Long URL:

https://example.com/products/category/item/123456789

                 ↓

URL Shortener

                 ↓

Short URL:

https://short.ly/aZ91x
